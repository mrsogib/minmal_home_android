# WaveLauncher 🌊

A minimalist, customizable Android Launcher built with **Kotlin** and **Jetpack Compose**.

## Features
* **Minimalist Home Screen**: Displays favorite apps, clock, date, and battery percentage.
* **Niagara-Style Alphabet Rail**: Smooth side-alphabet bar with wave scaling animations to jump directly to apps.
* **App Drawer & Search**: Dynamic search bar with alphabetical or usage-based sorting.
* **Custom Gesture Support**:
  * Swipe Left / Right / Up for custom shortcuts.
  * Swipe Down for Status Bar / Quick Settings.
  * Pinch In for Settings, Pinch Out for Hidden Apps.
  * Double-tap to lock screen.
* **Wallpaper Slideshow**: Automatically rotates local wallpapers at user-defined time intervals.
* **App Renaming & Hiding**: Customize app labels or hide private apps.

## Requirements
* **Android Studio**: 2024.1+ (Ladybug or newer recommended)
* **Minimum SDK**: Android 8.0 (API Level 26)
* **Target SDK**: Android 15 (API Level 35)
